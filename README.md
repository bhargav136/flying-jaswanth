# Flying Jaswanth 🚀

A Flappy Bird style meme browser game featuring custom player avatar, background theme, obstacles, and meme sound effects.

## 🎮 Play Live
- **Production**: Deployed on Vercel

## 🌟 Features
- **Bird Character**: Jaswanth (custom transparent sprite).
- **Pillars**: Chicken body with Jaswanth head mascot badges.
- **Background Music**: Electronic beat track.
- **Game Over Screen & Audio**: Jaswanth reaction photo with dialogue sound bite (*"Ainda? Bagainda?"*).
- **Controls**:
  - Desktop: `[Space]` or `[Up Arrow]` to flap
  - Mobile: Tap screen to flap
